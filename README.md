# 回診前症狀紀錄（試用版）

免疫治療（IO）與抗體藥物複合體（ADC）門診的**到診前輔助工具**。
病人在候診時用手機填，填完產生一份「看診用摘要」，直接把畫面拿給醫師看。

**資料完全不離開病人的手機**：沒有後端、不上傳、不寫任何伺服器，關掉網頁就沒了。

## 這不是什麼

* 不是監測系統。沒有人會在看診前回覆您。
* 不產生 CTCAE 分級。題目設計對應 CTCAE v6.0 的分級條件所需證據，
  但**分級是醫師的判斷**，本工具只整理病人提供的資訊。
* 繁體中文題目為自譯，非 NCI 語言學驗證版本，僅作臨床溝通輔助。

## 題目依據

CTCAE v6.0（2025 發布，2026-01-20 勘誤），NCI/CTEP。
每題對應某個 CTCAE 詞條分級條件所需的證據，而非 PRO-CTCAE 的抽象量尺。
日常活動兩題照 CTCAE 對 instrumental / self-care ADL 的官方定義措辭。

紅旗規則為本院自訂，不是 CTCAE 或 PRO-CTCAE 的一部分。
